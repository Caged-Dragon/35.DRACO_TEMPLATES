## Brand & Style

This design system powers an elite commercial authentication kit and UI template marketplace. Built for top-tier product designers, enterprise engineers, and premium creative studios, it presents authentication not merely as a utilitarian gateway, but as the high-impact overture to modern software products.

The aesthetic philosophy merges **Architectural Modernism** with **Tactile Glassmorphism** and disciplined minimalism. It prioritizes razor-sharp typography, deliberate negative space, and deep cinematic canvas tones that elevate the perceived value of any software system. Across every variant—from ultra-clean minimal workspaces to dense multi-factor authentication modules—the interface conveys cryptographic security, precision engineering, and effortless visual authority.

### Key Visual Tenets
- **Cinematic Precision**: Uncluttered structural foundations paired with atmospheric ambient glows and calibrated depth.
- **Architectural Hierarchy**: Strict optical alignment, refined structural framing, and purposeful spatial balance.
- **Tactile Cryptography**: Interactive tokens, security pins, and biometric cues communicate trust through micro-fidelity and immediate tactile feedback.

## Colors

The core color system is calibrated for deep immersive dark surfaces that eliminate visual noise while spotlighting mission-critical interactive fields, identity authenticators, and call-to-action anchors.

- **Primary (`#6366F1` - Electric Indigo)**: The operational anchor used for focused input halos, verification submit actions, active security states, and interactive signposts.
- **Secondary (`#F59E0B` - Architectural Gold)**: Used sparingly for premium badge markers, enterprise workspace tags, security clearance tiers, and high-value transactional highlights.
- **Tertiary (`#06B6D4` - Cyber Teal)**: Dedicated to data stream indicators, biometric pulses, hardware token status, and passkey authentication cues.
- **Neutral (`#090A0F` - Obsidian Deep Space)**: A bespoke, non-neutral black with deep blue undertones that anchors the viewport canvas, providing infinite depth without washed-out gray casts.

### Semantic & Surface Rules
- Surface depths build up from base canvas `#090A0F` through surface elevations `#11131F`, `#181A2A`, and `#23263B`.
- High-contrast text uses `#F8FAFC` for primary legible copy and `#94A3B8` for secondary labels, ensuring strict WCAG AAA compliance against all elevated dark card backings.
- Error states strictly leverage `#F43F5E` (Crimson Pulse) with dedicated low-opacity tinted washes for inline input validation.

## Typography

The typography architecture balances structural technical authority with effortless organic readability. 

- **Display & Headline Roles**: Space Grotesk injects mathematical precision, crisp terminals, and technological edge into view titles, welcome headers, and security verifications.
- **Body Hierarchy**: Plus Jakarta Sans delivers warm, highly legible proportional geometry across descriptive subtext, legal terms, and modal notifications.
- **Microcopy & Data Roles**: Inter provides optical neutrality for system labels, input instructions, error strings, and metadata tags.
- **One-Time Password / Pin Codes**: Space Grotesk is leveraged in monospace-oriented tracking for OTP confirmation boxes and recovery passphrases.

## Layout & Spacing

The layout model adapts seamlessly between modular full-screen hero split layouts and focused centered card views.

### Grid Framework & Viewport Adaptability
- **Desktop (1024px and up)**: 12-column dynamic fluid layout anchored to a max-width container of `1440px`. Split-screen templates allocate either a balanced 6/6 split or an asymmetrical 5/7 split for feature showcase panels versus authentication forms. Outer margin is locked to `2.5rem` (`space-xl`).
- **Tablet (768px - 1023px)**: 8-column layout. Media showcase sidebars collapse into a high-impact branded top banner or ambient card header, shifting the form card to an elevated, centered 6-column focus.
- **Mobile (320px - 767px)**: 4-column layout with fluid margin compression down to `1.25rem`. Complex dual layouts stack into single-column vertical flows with full-bleed touch targets and pinned bottom-sheet navigation.

### Rhythm & Stack Spacing
- Vertical form grouping adheres strictly to a base 8-point spatial curve. Field labels and their corresponding input frames maintain a tight `space-xs` (4px) to `space-sm` (8px) association.
- Separate input field rows use `space-md` (16px) separation.
- Form groupings, social federated login dividers, and action footers transition across `space-lg` (24px) to `space-xl` (40px) intervals to preserve visual pacing.

## Elevation & Depth

Depth is established via **layered translucent surfaces** and **chromatic ambient dispersion**, avoiding dated heavy dropped shadows.

### Depth Hierarchy
1. **Canvas (Base 0)**: Obsidian ground (`#090A0F`). Houses optional subtle dynamic background radial mesh gradients (Electric Indigo at 12% opacity with 120px blur radius).
2. **Structural Panels (Elevation 1)**: Subdued surfaces with `#11131F` at 70% opacity, layered with a CSS `backdrop-filter: blur(20px)` and framed with a crisp hairline border (`rgba(255, 255, 255, 0.08)`).
3. **Interactive Cards & Modals (Elevation 2)**: Form containers and split cards utilize elevated `#181A2A` tinted glass fills with dual-layered boundary outlines: an inner stroke of `rgba(255, 255, 255, 0.12)` paired with an outer atmospheric bloom (`box-shadow: 0 24px 48px -12px rgba(0, 0, 0, 0.65), 0 0 32px rgba(99, 102, 241, 0.08)`).
4. **Floating Popovers & Overlays (Elevation 3)**: Dropdowns, tooltip popovers, and biometrics confirmation sheets float at `#23263B` with high-luminosity edge highlights (`rgba(255, 255, 255, 0.2)` top edge highlight, `rgba(0, 0, 0, 0.8)` deep drop spread).

## Shapes

The design system implements a refined **Level 2 Roundedness** profile (`0.5rem` / 8px base radius). This produces tailored, architectural corners that feel solid, contemporary, and engineered without tipping into hyper-casual pill aesthetics.

### Geometric System
- **Base Inputs, Action Buttons, Checkboxes**: `rounded-md` (8px) for structural crispness.
- **Card Enclosures & Form Containers**: `rounded-lg` (16px) to `rounded-xl` (24px) on primary desktop cards to create soft framing against screen perimeters.
- **Interactive Badges & Security Avatars**: Full-round pills reserved strictly for small dynamic status pills, passkey indicators, and enterprise tier tags.
- **Border Treatment**: Consistent hairline stroke weight of `1px` across all nested containers, preserving clinical precision.

## Components

### 1. Primary & Secondary Buttons
- **Primary Action (Sign In / Verify)**: Background filled with Primary Electric Indigo (`#6366F1`) transitioning on hover to `#4F46E5`. Height locked to 48px with a subtle top edge inner shadow (`inset 0 1px 0 rgba(255, 255, 255, 0.25)`). Font: `label-lg`, center-aligned.
- **Secondary / Federated (Google, Apple, GitHub SSO)**: Surface `#181A2A` with `1px` border of `rgba(255, 255, 255, 0.1)`. Interactive hover state illuminates border to `rgba(99, 102, 241, 0.5)` with micro-translation of 1px upwards.
- **Destructive / Reset Action**: Transparent backdrop with `#F43F5E` typography and soft hover tint.

### 2. Form Inputs & Floating Fields
- **Default State**: Surface fill `#11131F`, height 48px, horizontal padding `space-md` (16px). Border: `1px solid rgba(255, 255, 255, 0.1)`. Placeholder text formatted in `body-md` at `#64748B`.
- **Focused State**: Border shifts dynamically to Primary `#6366F1`, supported by an outer ambient glow (`0 0 0 3px rgba(99, 102, 241, 0.25)`).
- **Error State**: Border shifts to `#F43F5E` accompanied by an inline status alert icon and red micro-glow.
- **Password Masking Toggle**: Subtle vector eye icon pinned `space-md` from the right edge with high-luminance interactive hover.

### 3. One-Time Passcode (OTP) & Pin Input
- 6-slot segregated input series. Each block sized 48px width by 56px height.
- Typography set in Space Grotesk `code-mono`.
- Caret features an animated pulse in Primary Indigo. Auto-focus shift sequence forwards and backwards.

### 4. Selection Controls (Checkboxes & Radios)
- **Checkboxes ("Remember this device")**: Custom 18px square with `rounded-sm` (4px). Unchecked: background `#11131F` with `rgba(255, 255, 255, 0.2)` border. Checked: `#6366F1` fill with sharp optical-white checkmark vector.
- **Radio Buttons (Role / Auth Method Selectors)**: 20px dual concentric circle. Active center illuminated with high-contrast dot.

### 5. Authentication Cards & Split Containers
- **Floating Form Canvas**: Fixed width of 440px on desktop screens, fully fluid on mobile. Multi-layer backdrop blur styling with `space-xl` internal padding.
- **Branded Split Showcase**: Left or right showcase companion containing ambient artwork, customer social proof, or live terminal verification mockups, framed by a soft vertical border separator.

### 6. Badges & Security Indicator Chips
- Rounded pill containers housing an animated status dot (e.g., green 256-bit SSL Active indicator, WebAuthn Passkey Ready).
- Typography set to `label-sm` with upper-case tracking and high-contrast tinted fills.
