# Blueprint Studio

Standalone sign-in UI template #09.

## Run
Open `index.html` directly in a browser, or serve this folder with any static file server.

## Included UI
- Email address or mobile number field
- Password field with show/hide control
- Remember me, forgot password, sign-in and create-account affordances
- Responsive layout for mobile, tablet and desktop
- Reduced-motion support

**UI only:** this template does not authenticate users or send credentials anywhere. Connect `script.js` to a secure backend before production use.
